# 🐾 Animal Park

Animal Park is a full-stack pet-care platform designed to bring essential pet-care services into one place. Users can book veterinary consultations and grooming services, shop for pet products, manage appointments and orders, and interact with an AI-powered chatbot.

## ✨ Features

- 🩺 Veterinary consultation booking
- ✂️ Grooming service booking
- 🛒 Pet product marketplace
- 📦 Order management
- 👤 User authentication
- 🤖 AI-powered chatbot
- 💬 Real-time communication
- 📍 Location-based features
- ⭐ Reviews and ratings
- 📊 User dashboard

## 🛠️ Tech Stack

### Frontend
- Next.js
- React
- JavaScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Socket.IO

### Other Technologies
- REST APIs
- JWT-based authentication
- TypeScript configuration
